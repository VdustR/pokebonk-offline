# PokéBonk Offline

Private builder for self-contained PokéBonk desktop and Android unlock-all apps.

The builder downloads the published game at build time. Game assets, user saves,
and signing keys are not tracked in this repository. The original game and art
remain credited to Charcher and their respective creators.

Implementation and verification are in progress. See the eventual release notes
for the exact game build, builder revision, supported platforms, and test limits.
