# Upstream 0.9.23 resource review

The official game reported 0.9.23, build `mwaj5w8h`, on November 11, 2026 (Asia/Taipei). The update tracker had no discussion comments at review time. The official game page has no public comment section; its Discord discussion was not accessed.

The review compares the pristine 0.9.22 (`mw88813m`) snapshot with the official module/style graph and versioned catalogs. The asset-version table and season-three 251-species limit are unchanged. All 16 data catalogs and 21 environment atlas JSON files were fetched from their official versioned URLs and match the accepted snapshot byte for byte. Evaluated configuration arrays differ only in release history and Johto challenge descriptions; asset domains remain unchanged.

All 94 calls to the configuration's asset/data URL factories retain the same argument structures after normalizing local identifier names. Main/menu resource literals and resource-bearing template strings are unchanged. Stylesheet changes adjust HUD density, settings controls, trainer layout and expedition scrolling without adding resource URLs. Desktop and event lazy modules, Three.js, preload helpers and i18n wiring match after build-filename normalization. Language modules update messages for the new gameplay behavior.

The independent contract retains every existing required resource, updates the versioned graph filenames and pins the reviewed pristine inputs. The legal page changes only Cloudflare's reversible email-obfuscation tokens; decoding them yields identical legal content. Original bytes remain preserved in the snapshot. Accepted binary assets are reused only where the asset-version table yields the same versioned URL; new graph resources are captured from the official site.

Upstream changes include save recovery, ordered League encounters, expedition shiny-equipment filtering, Raikou behavior, co-op timing and audio recovery. The offline adapter and native origins remain unchanged. Existing native acceptance exercises manual/autosave recovery, corrupt-save rejection, resource decoding, local persistence, representative gameplay and network isolation. These checks do not establish every upstream gameplay balance change, online co-op behavior or physical Android acceptance.

Local candidate validation prepared and verified 3,874 offline payload hashes. All 3,801 binary, font and SVG inputs match 0.9.22 after versioned graph-name normalization. The complete Electron run passed desktop/event/appearance/Stellar resources, victory summaries with a deliberately missing-image control, nine representative gameplay scenarios, manual and automatic recovery after process restart, corrupt-save rejection and network isolation. Local tests use disposable profiles; the installed user's suspended run is a separate installation acceptance gate.

All 105 unit/regression tests and 60 compiler probes passed. Preparation with upstream network access explicitly denied also generated and verified the same 3,874-file payload. Existing negative controls still reject changed/new URL producers and omitted required images, including the Stellar assets and MP3 tracks.

The initial packaged Linux CI run exposed a restore/input-focus precondition in the fullscreen smoke. A real Linux delayed-restore comparison discriminated the original DOM-only ordering from native restore/focus completion. The test now waits for native readiness and retains its existing gameplay assertions. A small production-shell fixture repeats capture after delayed restoration and rejects withheld restoration; local Linux and macOS checks passed.
