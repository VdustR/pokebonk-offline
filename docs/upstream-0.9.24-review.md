# Upstream 0.9.24 resource review

Observed November 12, 2026 (Asia/Taipei): the official game reports 0.9.24,
build `mwc3y990`. The update tracker had no comments when read. The game page
has no public comment section; Discord discussion was not accessed.

The comparison starts from the accepted 0.9.23 snapshot. The resource-version
table and season-three 251-species domain are unchanged. All 16 data catalogs
and 21 environment atlas JSON files were fetched from their official versioned
URLs and are byte-identical. Evaluated configuration arrays differ only by the
new release-history entry. It describes fixed Swinub experience rewards and
exclusion of affected online runs from rankings; online rankings remain outside
the offline adapter's supported features.

All 94 asset/data factory calls retain identical argument structures after
local-identifier normalization. Main and menu resource literals and templates
have no additions or removals. Styles, desktop/event lazy modules, entry and
support modules match after versioned-filename normalization. Language modules
add the release messages. The legal page changes only reversible Cloudflare
email-obfuscation tokens; decoded content is identical.

The review retains every required resource and updates only the versioned graph
paths and reviewed pristine hashes. Graph fonts/images/SVGs match the accepted
bytes after filename mapping. Accepted binary resources are reused only when
the resource-version table selects exactly the same versioned URL. The new
source graph and data catalogs were obtained independently of the candidate
manifest, so acquisition does not approve its own completeness.

The local release command verifies the candidate payload, native resource
decoding, representative gameplay, manual/autosave restarts, corrupt-save
preservation and network isolation before publication. Those checks do not
establish every upstream balance change or physical Windows/Android/Intel Mac
behavior. The two historical Linux profile-reset observations remain tracked
without a speculative production fix; they are not an automatic publication
blocker under the bounded local release policy.
