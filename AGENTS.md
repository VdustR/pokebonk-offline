# Repository agent guide

For upstream snapshot upgrades, acquisition/resource review, or changes to the
local release workflow, read the repository's
[pokebonk-upgrade skill](.agents/skills/pokebonk-upgrade/SKILL.md).

The skill routes to the maintained procedures; keep commands and recovery details
in those documents. It does not expand the user's selected delivery endpoint.

Use targeted checks while investigating. Before repeating a full preparation,
identify the changed input or invalidated evidence. Resume through the release
command so it can verify completed stages; do not discard its journal to force a
fresh build. Diagnose a current failure before retrying an expensive stage.

Keep authored source, comments and repository documentation in American English.
